# 灑水與泡沫滅火系統配管檢討

自動撒水設備與泡沫滅火設備是台灣建築物最常見的兩種水系自動滅火系統。在進行消防審查或現場施工圖繪製時，撒水頭與泡沫噴頭的配置、管徑尺寸（配管管徑）以及放射區域劃分，是決定設計是否合規的核心要素。

本篇主要彙整自動撒水與泡沫系統在台灣法規下的設計標準、管徑與噴頭數量關係、以及常見的實務設計陷阱。

---

## 學習目標

1. **掌握撒水頭數量與配管管徑之對應關係**，並理解單一支管上的頭數限制。
2. **掌握泡沫滅火設備之放射區域面積限制與噴頭水平距離規範**。
3. **理解水力計算與傳統表格法（管稱法）的適用時機與流速限制**。
4. **避開常見的現場安裝陷阱**（如迴水板淨空不足、樑下未增設、排水管配置錯誤）。

---

## 核心設計規範

### 1. 自動撒水設備：管徑與撒水頭數量關係
依據台灣消防設計常規，配管管徑與撒水頭數量的配比基準如下表所示：

| 標稱管徑 (公厘 mm) | 標稱管徑 (英制 Inch) | 撒水頭設置數量 (個) | 備註 |
| :--- | :--- | :---: | :--- |
| **25 mm** | 1" | **2 個以下** | 支管最末端管徑 |
| **32 mm** | 1-1/4" | **3 個以下** | |
| **40 mm** | 1-1/2" | **5 個以下** | |
| **50 mm** | 2" | **10 個以下** | |
| **65 mm** | 2-1/2" | **30 個以下** | |
| **80 mm** | 3" | **60 個以下** | |
| **90 mm** | 3-1/2" | **100 個以下** | 實務上多直接升至 100A |
| **100 mm 以上**| 4" 以上 | **100 個以上** | |

> ⚠️ **重要限值**：每一直接接裝撒水頭之**支管**上，所裝設之撒水頭數量**不得超過 8 個**。

### 2. 泡沫滅火設備：放射區域與配管規範
泡沫滅火設備之管徑主要是透過**水力計算**判定，並非單純比照撒水頭的表格。其系統設計核心規範如下：
* **放射區域面積限制**：泡沫噴頭之每一放射區域，其樓地板面積應在 **50 平方公尺以上，100 平方公尺以下**。
* **放射水平距離**：防護對象之任一點至泡沫噴頭之水平距離，應在 **2.1 公尺以下**。
* **泡沫水溶液配管專用性**：泡沫配管必須為專用，管材採用符合 CNS 標準之熱浸鍍鋅鋼管，且壁厚需符合耐壓要求（低壓式 Sch 40 以上，高壓式 Sch 80 以上）。

## 實務圖說審查與現場安裝陷阱

### 陷阱一：支管串接超過 8 顆撒水頭
* **說明**：部分設計為了節省幹管（Cross Main）長度，直接將 9 或 10 顆撒水頭串接在同一條支管上（Branch Line）。
* **法規基準**：直接安裝撒水頭之支管，頭數上限為 8 顆。
* **正確做法**：當頭數超過 8 顆時，應將管路拆分為兩條支管，或將幹管延伸至中間進行雙向配管。

### 陷阱二：天花板樑下阻礙未增設撒水頭
* **說明**：當天花板下設有大型風管、電纜架、或結構樑，且其寬度超過 **120 公分** 時，撒水頭的放射水流會被阻擋。
* **法規基準**：寬度超過 120 公分之風管等障礙物下方，應增設撒水頭。
* **正確做法**：設計圖說上需標註風管下方之增設撒水頭，並將其計入該區的配管管徑檢算中。

### 陷阱三：末端查驗閥二次側未設限流孔
* **說明**：為測試系統最遠端放水壓力，每組流水檢知裝置皆需在最遠支管末端裝設「末端查驗閥」。部分現場隨意使用一個球閥作為查驗閥，並無安裝限流孔（節流孔）。
* **法規基準**：查驗閥管徑應在 25 mm 以上，且二次側必須設有與撒水頭放水性能同等（K值相同）之限流孔。
* **正確做法**：採用一體式末端查驗閥組，或在二次側加裝對應尺寸之節流片，並接引排水管至安全處。

## 相關法規依據

1. **《各類場所消防安全設備設置標準》**
   * 第 45、46 條：撒水頭配置與水平距離。
   * 第 56 條：末端查驗閥配置規範。
   * 第 70 ~ 80 條：泡沫滅火設備放射區域、水平距離與配管規範。
2. **《建築技術規則建築設備編》**
   * 第二章 避難實務與消防配管磨擦損失水力計算標準。
