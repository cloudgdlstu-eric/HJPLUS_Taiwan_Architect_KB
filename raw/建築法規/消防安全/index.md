# Fire Safety

## Skills

* [smoke-exhaust-review](排煙窗法規檢討/smoke-exhaust-review/SKILL.md) - This skill should be used when evaluating smoke exhaust compliance for buildings in Taiwan, including windowless floor determination, smoke compartment partitioning, smoke exhaust window effective area calculations, and supplementary code checks.
* [generator-room-fire-safety](generator-room-fire-safety/SKILL.md) - This skill should be used when reviewing the architectural and MEP designs of a generator room, specifically checking the fuel tank capacity, maintenance clearances, and ventilation requirements.
* [sprinkler-foam-piping-review](灑水與泡沫滅火系統配管檢討/sprinkler-foam-piping-review/SKILL.md) - This skill should be used when reviewing fire sprinkler and foam piping designs in Taiwan, checking the pipe sizes (diameters) based on the number of sprinkler/foam heads, layout rules, and flow calculations.
* [fire-equipment-requirements-review](各類場所消防安全設備設置檢討/fire-equipment-requirements-review/SKILL.md) - This skill should be used when analyzing or generating the required fire safety equipment checklist for a building in Taiwan, evaluating parameters like occupancy usage, height, floors, total area, basement floors, and windowless floors.
